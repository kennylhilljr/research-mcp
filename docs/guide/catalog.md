# Catalog of skills, agents and commands

Every skill, agent persona and command in `.claude/` carries its own version, so a change to one of them can be tracked and rolled back on its own.

- **Semver per file.** The version lives in the front matter as `metadata.version` (for example `1.0.0`). It sits under `metadata:` so the same files work in Claude Code, on claude.ai and through the Skills API.
- **Bump rules.** Patch (`1.0.1`) for wording fixes that do not change behavior. Minor (`1.1.0`) for new steps, inputs or outputs that keep existing use working. Major (`2.0.0`) for changes that break how the file is used: a renamed skill, removed outputs, a different gate or persona.
- **Changelog required.** Each skill and agent ends with a `## Changelog` table, and it must have a row for the current version. spec-lint fails without it.
- **Generated catalog.** The tables below are generated by `node tools/sdd/cli.mjs catalog`. CI runs `node tools/sdd/cli.mjs catalog --check` and fails when the catalog is out of date.
