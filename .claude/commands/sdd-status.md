Report the status of the spec-driven work in this repository. Scope: $ARGUMENTS (all components if empty).

1. Read the doc map (`docs/README.md`, or the file named by `paths.docMap` in `sdd.config.json`) for the latest version and status of every document.
2. Read `docs/trace/index.yaml` for each component's audit status, last audit date and commit, drift and next action.
3. Read `docs/trace/coverage.md` (generated by trace-check) for the evidence state of each criterion: planned, test linked, passing, failing, deferred, excepted, drifted or gap. Evidence is not kept in the test plan.
4. For each component, report in one table: scope, PRD status, LLD status, criteria test linked out of total, audit status, drift, and the next checkpoint:
   - the intake checkpoint if Section 1 of the parent PRD (the problem framing) is not approved;
   - Gate 1 if the PRD is not approved;
   - Gate 2 if the SPEC is not approved;
   - Gate 3 if the component's LLD is not approved;
   - otherwise the next task in the milestone plan.
5. List open support items and the queue. This reference profile uses the combined ordering S0 > S1 > P1 > S2 = P2 > S3 = P3 > S4 (a local choice).
6. Do not change any files.
